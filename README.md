# React + Next.js in 123 Days

A public learning log: moving from Java / Spring Boot backend development to full-stack with React and Next.js.

I'm a backend developer (Java, Spring Boot, REST APIs, MySQL, Docker) and a final-year CSE student from Kolhapur, India. This repo tracks my progress day by day.

**Started:** 30 October 2026
**Follow along:** [@Shreyas9356](https://x.com/Shreyas9356) on X (#buildinpublic)

## Goal

By Day 123, I want:

- A full-stack dashboard (React + TypeScript + Tailwind + Spring Boot + JWT + MySQL)
- A Next.js app backed by my own Spring Boot API
- Both projects deployed with live URLs
- Clean READMEs and an updated resume

## Rules

- 3 to 4 hours a day
- About 30% reading, 70% typing code
- At least 1 commit every study day
- Do not move on until the practice task works
- Official docs first (react.dev, nextjs.org/learn)
